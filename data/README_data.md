# Dataset

The raw datasets are not included in this repository due to file size.

Download the GEOSCRAPE/Martin zircon database files from the original source and place them locally in the project root or in a local data directory.

Expected files:

- 2021-10-FWQ7DT_Martin_data.csv
- 2021-11-FWQ7DT_Martin_data-sources.csv
- 2021-12_FWQ7DT_Martin_Data-Description.xlsx

Additional older U-Pb datasets used in early experiments:

- Database_v2.1_part1.xlsx
- Database_v2.1_part2.xlsx
- Database_v2.1_part3.xlsx

These files are ignored by Git through .gitignore.
